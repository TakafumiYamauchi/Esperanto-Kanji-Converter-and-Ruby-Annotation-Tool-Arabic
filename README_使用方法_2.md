# دليل استخدام أداة استبدال النصوص الإسبرانتية بالأحرف الصينية (كانجي) وإضافة تعليقات توضيحية

## المقدمة

مرحباً بك في دليل استخدام أداة استبدال النصوص الإسبرانتية بالأحرف الصينية (كانجي) وإضافة تعليقات توضيحية. هذه الأداة مصممة لمساعدتك في تحويل نصوص بلغة الإسبرانتو واستبدالها بأحرف صينية (كانجي) أو إضافة تعليقات توضيحية بتنسيق HTML لتسهيل تعلم وفهم اللغة.

### ما الذي يمكنك فعله باستخدام هذه الأداة؟

- استبدال كلمات وجذور الإسبرانتو بأحرف صينية (كانجي) أو ترجمات عربية
- إضافة تعليقات توضيحية بتنسيق HTML (نظام روبي Ruby) للكلمات الإسبرانتية
- تخصيص قواعد الاستبدال من خلال ملفات JSON
- إنشاء ملفات JSON خاصة لاستبدال النصوص
- معالجة نصوص كاملة من الإسبرانتو مع خيارات متعددة للإخراج

## الصفحة الرئيسية - استبدال نصوص الإسبرانتو

### الخطوات الأساسية لاستخدام الأداة

#### 1. اختيار ملف JSON لقواعد الاستبدال:

عند بدء استخدام الأداة، ستحتاج أولاً إلى اختيار ملف JSON يحتوي على قواعد الاستبدال:

- **استخدام ملف JSON الافتراضي**: الخيار الأبسط للمبتدئين، حيث يستخدم ملف مضمن مسبقاً مع التطبيق
- **تحميل ملف**: يمكنك تحميل ملف JSON مخصص إذا كان لديك واحد بالفعل

إذا كنت ترغب في تنزيل ملف JSON تجريبي للاستبدال، يمكنك الضغط على "تنزيل ملف JSON تجريبي" تحت قسم "تنزيل ملف JSON تجريبي (للاستبدال)".

#### 2. اختيار تنسيق الإخراج:

هناك عدة خيارات لتنسيق النص الناتج:

- **تنسيق HTML مع تعليقات Ruby وضبط الحجم**: يضيف تعليقات توضيحية بحجم مناسب فوق النص الإسبرانتي
- **تنسيق HTML مع تعليقات Ruby وضبط الحجم واستبدال الأحرف (كانجي)**: يستبدل النص الإسبرانتي بأحرف كانجي مع عرض النص الأصلي كتعليق توضيحي
- **تنسيق HTML**: تعليقات توضيحية بدون ضبط تلقائي للحجم
- **تنسيق HTML مع استبدال الأحرف (كانجي)**: استبدال مع تعليقات توضيحية بدون ضبط الحجم
- **تنسيق باستخدام الأقواس**: استخدام الأقواس بدلاً من تعليقات HTML (مثل: كلمة(تعليق))
- **تنسيق باستخدام الأقواس واستبدال الأحرف (كانجي)**: استبدال بالأحرف مع وضع النص الأصلي بين أقواس
- **الاحتفاظ فقط بالنص المُستبدل (استبدال بسيط)**: استبدال الكلمات دون إضافة تعليقات أو أقواس

#### 3. اختيار مصدر النص الإدخالي:

يمكنك إدخال النص الإسبرانتي بطريقتين:

- **إدخال يدوي**: كتابة النص مباشرة في مربع النص
- **تحميل ملف**: تحميل ملف نصي بترميز UTF-8 يحتوي على النص الإسبرانتي

#### 4. إدخال النص وتحديد خيارات العرض:

بعد اختيار مصدر النص، ستحتاج إلى:

- كتابة أو تحميل النص الإسبرانتي
- اختيار شكل عرض الأحرف الخاصة بلغة الإسبرانتو:
  - **إضافة علامة تمييز فوق الحرف** (ĉ → c + ˆ)
  - **صيغة x** (ĉ → cx)
  - **صيغة ^** (ĉ → c^)

#### 5. معالجة النص وعرض النتيجة:

- انقر على زر "إرسال" لمعالجة النص
- ستظهر النتيجة في قسم خاص أسفل الصفحة
- يمكنك عرض النتيجة إما كمعاينة HTML أو كنص ناتج حسب التنسيق المختار
- يمكنك تنزيل النتيجة باستخدام زر "تنزيل النتيجة"

### ميزات متقدمة في الصفحة الرئيسية

#### الإعدادات المتقدمة (المعالجة المتوازية):

للنصوص الكبيرة، يمكنك تسريع المعالجة باستخدام المعالجة المتوازية:

- فعّل خيار "استخدام المعالجة المتوازية"
- حدد عدد العمليات المتزامنة (من 2 إلى 4)

#### خيارات معالجة خاصة:

يمكنك تحديد أجزاء معينة من النص لمعالجتها بطرق مختلفة:

- **تجاهل الاستبدال**: ضع النص بين علامتي **%** (مثال: `%نص لا تريد استبداله%`)
- **استبدال موضعي**: ضع النص بين علامتي **@** (مثال: `@نص للاستبدال بشكل موضعي@`)

## الصفحة الثانية - إنشاء ملف JSON لاستبدال النصوص

التطبيق يتضمن أيضاً صفحة ثانية تسمح لك بإنشاء ملفات JSON مخصصة لاستخدامها في استبدال النصوص. هذه الصفحة مفيدة للمستخدمين المتقدمين الذين يرغبون في تخصيص قواعد الاستبدال.

### الخطوات الأساسية لإنشاء ملف JSON

#### 1. تجهيز ملف CSV:

ملف CSV يحتوي على جذور الإسبرانتو والترجمات أو الأحرف الصينية المقابلة. يمكنك:

- رفع ملف CSV خاص بك
- استخدام الملف الافتراضي

يمكنك تنزيل ملفات CSV نموذجية مختلفة من قسم "ملفات نموذجية (للتنزيل)" للاطلاع على التنسيق المطلوب.

#### 2. تحضير ملف/ملفات JSON:

ستحتاج إلى ملفين من ملفات JSON:

- **ملف JSON لتجزئة الجذور الإسبرانتية**: يحدد كيفية تجزئة الكلمات في إسبرانتو إلى جذور
- **ملف JSON للنص المستبدل**: يحدد التنسيق المخصص لبعض الكلمات

يمكنك استخدام الملفات الافتراضية أو تحميل ملفات خاصة بك.

#### 3. إعدادات متقدمة (المعالجة المتوازية):

مماثلة للصفحة الرئيسية، يمكنك تفعيل المعالجة المتوازية وتحديد عدد العمليات المتزامنة.

#### 4. إنشاء ملف JSON النهائي:

- انقر على زر "إنشاء ملف JSON للاستبدال"
- انتظر حتى تكتمل العملية
- قم بتنزيل الملف الناتج باستخدام زر التنزيل الذي سيظهر بعد اكتمال العملية

## شرح تفصيلي للميزات الرئيسية

### 1. تنسيقات الإخراج

#### تنسيق HTML مع تعليقات Ruby:

هذا التنسيق يضيف تعليقات توضيحية فوق كلمات الإسبرانتو، مشابهة لنظام الروبي الياباني. مثال:

```html
<ruby>esperanto<rt>إسبرانتو</rt></ruby>
```

عند عرضه، سيظهر النص هكذا: النص الأصلي "esperanto" مع تعليق توضيحي "إسبرانتو" فوقه.

#### تنسيق HTML مع ضبط الحجم:

يضيف تعليقات توضيحية مع ضبط تلقائي لحجم التعليق بناءً على طول النص. هذا مفيد عندما تكون الترجمة أطول بكثير من الكلمة الأصلية.

#### تنسيق الأقواس:

بدلاً من استخدام HTML، يضع الترجمة أو التعليق بين قوسين. مثال:
```
esperanto(إسبرانتو)
```

#### تنسيق الاستبدال:

يستبدل كلمات الإسبرانتو بالأحرف الصينية أو الترجمات العربية مع الحفاظ على بنية الجملة.

### 2. معالجة الأحرف الخاصة بالإسبرانتو

لغة الإسبرانتو تحتوي على أحرف خاصة مثل (ĉ، ĝ، ĥ، ĵ، ŝ، ŭ)، ويمكن عرضها بعدة طرق:

- **إضافة علامة تمييز فوق الحرف**: الشكل الرسمي للأحرف الإسبرانتية (ĉ، ĝ...)
- **صيغة x**: تمثيل الأحرف الخاصة بإضافة حرف x بعدها (cx، gx...)
- **صيغة ^**: تمثيل الأحرف الخاصة بإضافة علامة ^ بعدها (c^، g^...)

### 3. استخدام العلامات الخاصة للتحكم في الاستبدال

يمكن استخدام علامات خاصة للتحكم في كيفية معالجة أجزاء محددة من النص:

- **علامة %**: احتواء نص بين علامتي % يجعل النص غير قابل للاستبدال. مثال:
  ```
  Mi %neniam forgesos% tiun tagon.
  ```
  هنا، كلمة "neniam forgesos" لن يتم استبدالها.

- **علامة @**: احتواء نص بين علامتي @ يسمح باستبدال ذلك النص فقط بشكل موضعي. مثال:
  ```
  Mi @amas@ vin.
  ```
  هنا، فقط كلمة "amas" سيتم استبدالها حسب قواعد الاستبدال الموضعية.

## إنشاء ملفات مخصصة

### 1. ملف CSV للجذور والترجمات

ملف CSV يجب أن يحتوي على عمودين على الأقل:
- العمود الأول: جذر كلمة الإسبرانتو
- العمود الثاني: الترجمة العربية أو الأحرف الصينية المقابلة

مثال للتنسيق:
```
am,حب
dank,شكر
hom,إنسان
```

### 2. ملف JSON لتجزئة الجذور

يحدد هذا الملف كيفية تقسيم كلمات الإسبرانتو إلى جذور وكيفية التعامل مع اللواحق واللوائح. التنسيق العام هو:

```json
[
  ["جذر الكلمة", "أولوية الاستبدال", ["خيارات المعالجة"]]
]
```

على سبيل المثال:
```json
[
  ["am", "dflt", ["verbo_s1"]],
  ["hom", "dflt", ["ne"]]
]
```

- "am" هو جذر فعل، و "verbo_s1" يعني استخدام اللواحق الفعلية
- "hom" هو جذر، و "ne" يعني استخدام التنسيق الافتراضي

### 3. ملف JSON للنص المستبدل

يوفر هذا خيارات إضافية للتحكم في كيفية ظهور النص المستبدل، خاصة للكلمات التي تحتاج إلى معالجة خاصة.

## نصائح وحلول للمشكلات الشائعة

### النص لا يظهر بشكل صحيح:

- تأكد من أن ملف JSON للاستبدال يتوافق مع تنسيق الإخراج الذي اخترته
- تحقق من ترميز الملفات المرفوعة (يجب أن تكون UTF-8)
- للنصوص الطويلة، جرّب تقسيمها إلى أجزاء أصغر

### الاستبدال غير صحيح:

- راجع قواعد الاستبدال في ملف JSON
- استخدم علامات % لتجاهل أجزاء من النص التي لا ترغب في استبدالها
- للكلمات المتشابهة، ضع الكلمات الأطول أولاً في ملف CSV

### أداء بطيء:

- قم بتفعيل المعالجة المتوازية
- زيادة عدد العمليات المتزامنة (لكن لا تتجاوز عدد أنوية المعالج لديك)
- للملفات الكبيرة، قسمها إلى أجزاء أصغر ثم دمج النتائج لاحقاً
