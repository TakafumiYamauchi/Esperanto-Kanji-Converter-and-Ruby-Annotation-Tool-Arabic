# دليل استخدام أداة استبدال النصوص الإسبرانتية بالأحرف الصينية (كانجي) وإضافة التعليقات التوضيحية

## المقدمة

مرحباً بك في دليل استخدام أداة استبدال النصوص الإسبرانتية بالأحرف الصينية (كانجي) وإضافة التعليقات التوضيحية. هذه الأداة المتطورة مصممة لمساعدتك في:

- استبدال كلمات وجذور اللغة الإسبرانتو بالأحرف الصينية (كانجي) أو الترجمات العربية
- إضافة تعليقات توضيحية (Ruby) أعلى النص لتسهيل القراءة والفهم
- معالجة النصوص الإسبرانتية بتنسيقات مختلفة (HTML، الأقواس، إلخ)
- إنشاء قواعد استبدال مخصصة من خلال ملفات JSON

يتكون التطبيق من صفحتين رئيسيتين:
1. **الصفحة الرئيسية**: للقيام بعمليات الاستبدال على النصوص الإسبرانتية
2. **صفحة إنشاء ملفات JSON**: لإنشاء ملفات قواعد الاستبدال المخصصة

هذا الدليل سيشرح بالتفصيل كيفية استخدام جميع ميزات التطبيق خطوة بخطوة.

## نظرة عامة على التطبيق

هذا التطبيق مصمم لتحويل النصوص الإسبرانتية من خلال استبدال كلماتها وجذورها بالأحرف الصينية (كانجي) أو الترجمات العربية، مع إضافة تعليقات توضيحية (Ruby) للمساعدة في القراءة والفهم.

**كيف يعمل التطبيق؟**

1. يستخدم التطبيق قواعد استبدال محددة في ملفات JSON
2. يقوم بتحليل النص الإسبرانتي وتقسيمه إلى جذور وكلمات
3. يستبدل هذه الجذور والكلمات بالأحرف الصينية (كانجي) أو الترجمات العربية
4. يضيف تعليقات توضيحية (Ruby) أعلى النص حسب التنسيق المختار
5. يعرض النتيجة بالتنسيق المطلوب (HTML، الأقواس، إلخ)

## استخدام الصفحة الرئيسية

### تحميل ملف JSON لقواعد الاستبدال

عند بدء التطبيق، ستحتاج أولاً إلى تحديد ملف JSON الذي يحتوي على قواعد الاستبدال:

1. اختر "استخدام ملف JSON الافتراضي" أو "تحميل ملف"
   - إذا اخترت الملف الافتراضي، سيستخدم التطبيق الملف المضمن به
   - إذا اخترت تحميل ملف، فستتمكن من رفع ملف JSON مخصص

2. يمكنك تنزيل ملف JSON تجريبي من خلال النقر على "تنزيل ملف JSON تجريبي" في القسم المنسدل

![تحميل ملف JSON](https://i.imgur.com/example1.png) *(توضيح: هذه صورة افتراضية)*

**ملاحظة مهمة**: يجب أن يكون ملف JSON الذي ترفعه بالتنسيق الصحيح الذي يحتوي على ثلاثة قوائم:
- قائمة الاستبدال الشاملة (replacements_final_list)
- قائمة الاستبدال الموضعي للنصوص (replacements_list_for_localized_string)
- قائمة استبدال الجذور ثنائية الأحرف (replacements_list_for_2char)

### إعدادات المعالجة المتوازية

للنصوص الكبيرة، يمكنك تفعيل المعالجة المتوازية لتسريع عملية الاستبدال:

1. انقر على "إعدادات متقدمة (المعالجة المتوازية)" لتوسيع القسم
2. حدد مربع "استخدام المعالجة المتوازية" إذا كنت ترغب في تفعيل هذه الميزة
3. اضبط "عدد العمليات المتزامنة" (يوصى بـ 2-4 عمليات حسب مواصفات جهازك)

**متى تستخدم المعالجة المتوازية؟** نوصي باستخدامها عند معالجة نصوص كبيرة (أكثر من 1000 كلمة) حيث ستلاحظ تحسناً ملموساً في سرعة المعالجة.

### اختيار تنسيق الإخراج

يوفر التطبيق عدة تنسيقات للإخراج تناسب احتياجات مختلفة:

1. حدد تنسيق الإخراج المناسب من القائمة المنسدلة:
   - **تنسيق HTML مع تعليقات Ruby وضبط الحجم**: يضيف تعليقات Ruby مع ضبط حجمها حسب طول النص
   - **تنسيق HTML مع تعليقات Ruby وضبط الحجم واستبدال الأحرف (كانجي)**: يستبدل النص بالكانجي مع تعليقات Ruby
   - **تنسيق HTML**: إضافة تعليقات Ruby بدون ضبط الحجم
   - **تنسيق HTML مع استبدال الأحرف (كانجي)**: استبدال النص بالكانجي مع تعليقات HTML بسيطة
   - **تنسيق باستخدام الأقواس**: استخدام الأقواس بدلاً من تعليقات Ruby
   - **تنسيق باستخدام الأقواس واستبدال الأحرف (كانجي)**: استبدال النص بالكانجي واستخدام الأقواس
   - **الاحتفاظ فقط بالنص المُستبدل (استبدال بسيط)**: استبدال النص فقط بدون إضافة تعليقات

![اختيار تنسيق الإخراج](https://i.imgur.com/example2.png) *(توضيح: هذه صورة افتراضية)*

**نصيحة**: استخدم تنسيق HTML مع تعليقات Ruby وضبط الحجم للحصول على أفضل تجربة قراءة، خاصة عندما تكون التعليقات طويلة.

### إدخال النص الإسبرانتي

يمكنك إدخال النص بطريقتين:

1. **الإدخال اليدوي**:
   - اختر "إدخال يدوي" من خيارات مصدر النص
   - اكتب أو الصق النص الإسبرانتي في مربع النص

2. **تحميل ملف**:
   - اختر "تحميل ملف" من خيارات مصدر النص
   - انقر على زر "قم بتحميل ملف نصي" واختر ملفًا بتنسيق TXT أو CSV أو MD بترميز UTF-8

بعد إدخال النص، تحتاج إلى تحديد شكل عرض الأحرف الخاصة بلغة الإسبرانتو:
- **إضافة علامة تمييز فوق الحرف**: استخدام الأحرف مع العلامات (مثل ĉ، ĝ)
- **صيغة x**: استخدام الأحرف مع x (مثل cx، gx)
- **صيغة ^**: استخدام الأحرف مع ^ (مثل c^، g^)

أخيراً، انقر على زر "إرسال" لبدء عملية الاستبدال.

**ملاحظات استخدام خاصة**:
- يمكنك إحاطة أجزاء من النص بعلامة `%` (مثل `%نص لا تريد استبداله%`) لتجاهلها في عملية الاستبدال
- يمكنك إحاطة أجزاء من النص بعلامة `@` (مثل `@نص للاستبدال الموضعي@`) لتطبيق الاستبدال فقط داخل هذا الجزء

### معاينة وتنزيل النتائج

بعد معالجة النص، ستظهر النتائج:

1. إذا اخترت تنسيق HTML، ستظهر تبويبان:
   - **معاينة HTML**: لرؤية النص مع التعليقات التوضيحية كما سيظهر في المتصفح
   - **النتيجة (كود HTML)**: لعرض الكود HTML الذي يمكن نسخه واستخدامه في مشاريع أخرى

2. إذا اخترت تنسيقًا آخر، سترى النتيجة في تبويب واحد فقط

3. لتنزيل النتيجة، انقر على زر "تنزيل النتيجة"

![معاينة النتائج](https://i.imgur.com/example3.png) *(توضيح: هذه صورة افتراضية)*

**ملاحظة**: إذا كان النص طويلاً جداً (أكثر من 250 سطر)، سيتم عرض معاينة محدودة تشمل الأسطر الـ 247 الأولى والأسطر الثلاثة الأخيرة.

## استخدام صفحة إنشاء ملفات JSON

صفحة إنشاء ملفات JSON مخصصة لإنشاء ملفات قواعد الاستبدال التي يمكن استخدامها في الصفحة الرئيسية. للوصول إليها، استخدم القائمة الجانبية واختر "صفحة لإنشاء ملف JSON لاستبدال النصوص بالإسبرانتو بسلاسل نصية (كانجي)".

### تجهيز ملف CSV

الخطوة الأولى هي تجهيز ملف CSV يحتوي على جذور اللغة الإسبرانتية وترجماتها:

1. اختر كيفية التعامل مع ملف CSV:
   - **رفع ملف CSV**: رفع ملف CSV مخصص
   - **استخدام الملف الافتراضي**: استخدام الملف المضمن مع التطبيق

2. إذا اخترت رفع ملف CSV، انقر على زر "اختر ملف CSV" واختر ملفًا بتنسيق CSV
   - يجب أن يحتوي الملف على عمودين: الأول لجذور الإسبرانتو والثاني للترجمات العربية أو الأحرف الصينية

**تنسيق ملف CSV المطلوب**:
- العمود الأول: جذر الكلمة الإسبرانتية (مثل: "am", "lern", "libr")
- العمود الثاني: الترجمة أو الأحرف الصينية (مثل: "حب", "تعلم", "كتاب" أو الأحرف الصينية المقابلة)
- يجب أن يكون الملف بترميز UTF-8

### تحضير ملفات JSON للقواعد

بعد تجهيز ملف CSV، تحتاج إلى تحديد ملفات JSON التي تحتوي على قواعد تجزئة الجذور وإعدادات النص المستبدل:

1. اختر كيفية التعامل مع ملف JSON الخاص بتجزئة الجذور الإسبرانتية:
   - **رفع ملف JSON**: رفع ملف JSON مخصص
   - **استخدام الملف الافتراضي**: استخدام الملف المضمن مع التطبيق

2. اختر كيفية التعامل مع ملف JSON الخاص بالنص المستبدل:
   - **رفع ملف JSON**: رفع ملف JSON مخصص
   - **استخدام الملف الافتراضي**: استخدام الملف المضمن مع التطبيق

**ملاحظة حول ملفات JSON**:
- ملف تجزئة الجذور: يحدد كيفية تجزئة الكلمات الإسبرانتية إلى جذور وترتيب الاستبدال
- ملف النص المستبدل: يحدد النص البديل المخصص لبعض الكلمات

### إنشاء وتنزيل ملف JSON النهائي

بعد إعداد ملفات CSV و JSON، يمكنك إنشاء ملف JSON النهائي:

1. اختر تنسيق الإخراج الذي سيتم استخدامه في ملف JSON (باستخدام القائمة المنسدلة)
2. يمكنك تفعيل المعالجة المتوازية لتسريع العملية (من قسم الإعدادات المتقدمة)
3. انقر على زر "إنشاء ملف JSON للاستبدال"
4. بعد الانتهاء من العملية، انقر على زر "تنزيل قائمة الاستبدال النهائية" لتنزيل الملف

**ملاحظة**: قد تستغرق عملية إنشاء ملف JSON وقتًا طويلاً إذا كان ملف CSV كبيرًا. استخدم المعالجة المتوازية لتسريع العملية.

## ميزات خاصة وتقنيات متقدمة

### استخدام علامات % و @ للتحكم في الاستبدال

التطبيق يوفر آليتين خاصتين للتحكم في عملية الاستبدال:

1. **علامة % للتجاهل**:
   - أحط أي جزء من النص بعلامتي % (مثال: `%هذا النص لن يتم استبداله%`)
   - سيتم تجاهل هذا الجزء تمامًا في عملية الاستبدال وسيبقى كما هو
   - مفيد للأسماء والمصطلحات التي لا ترغب في استبدالها
   - يمكن أن يصل طول النص المحاط بعلامتي % إلى 50 حرفًا

2. **علامة @ للاستبدال الموضعي**:
   - أحط أي جزء من النص بعلامتي @ (مثال: `@هذا النص سيتم استبداله بشكل موضعي@`)
   - سيتم استبدال هذا الجزء فقط باستخدام قواعد الاستبدال الموضعي
   - مفيد عندما ترغب في استبدال جزء محدد فقط من النص
   - يمكن أن يصل طول النص المحاط بعلامتي @ إلى 18 حرفًا

**مثال عملي**:

```
La %Universala Esperanto-Asocio% kunvenis en @Tokio@ por diskuti pri lingva justeco.
```

في هذا المثال:
- لن يتم استبدال "Universala Esperanto-Asocio" وسيبقى كما هو
- سيتم استبدال "Tokio" باستخدام قواعد الاستبدال الموضعي فقط
- سيتم استبدال باقي النص باستخدام قواعد الاستبدال العامة

### أشكال عرض الأحرف الخاصة بلغة الإسبرانتو

اللغة الإسبرانتية تحتوي على أحرف خاصة مثل ĉ، ĝ، ĥ، ĵ، ŝ، ŭ. يوفر التطبيق ثلاثة خيارات لعرض هذه الأحرف:

1. **إضافة علامة تمييز فوق الحرف** (ĉ، ĝ، ...) - الشكل الرسمي للإسبرانتو
2. **صيغة x** (cx, gx, ...) - شائعة في الكتابة الرقمية
3. **صيغة ^** (c^, g^, ...) - بديل آخر شائع

يمكنك اختيار الشكل المفضل لديك عند إدخال النص وسيتم تطبيقه على النتيجة النهائية.

**ملاحظة**: بغض النظر عن الشكل الذي تختاره، يمكنك إدخال النص بأي من هذه الأشكال الثلاثة وسيقوم التطبيق بتحويله تلقائيًا.

## الأسئلة الشائعة

### ما هو الفرق بين تنسيقات الإخراج المختلفة؟

- **تنسيق HTML مع تعليقات Ruby وضبط الحجم**: يضيف تعليقات Ruby أعلى النص مع ضبط حجمها تلقائيًا حسب طول النص
- **تنسيق HTML مع استبدال الأحرف (كانجي)**: يستبدل النص الأصلي بالأحرف الصينية ويضع النص الأصلي في تعليقات Ruby
- **تنسيق باستخدام الأقواس**: يستخدم الأقواس بدلاً من تعليقات Ruby (مثال: كلمة(ترجمة))
- **الاحتفاظ فقط بالنص المُستبدل**: يعرض فقط النص المستبدل بدون تعليقات

### ما هو الحجم الأقصى للنص الذي يمكن معالجته؟

لا يوجد حد نظري لحجم النص، لكن عمليًا:
- للنصوص الصغيرة والمتوسطة (حتى 10000 كلمة): المعالجة سريعة ومباشرة
- للنصوص الكبيرة (أكثر من 10000 كلمة): استخدم المعالجة المتوازية لتحسين الأداء
- للنصوص الضخمة جدًا (أكثر من 100000 كلمة): قد تواجه بطء أو استهلاك عالٍ للذاكرة، ينصح بتقسيم النص

### كيف يمكنني إنشاء ملف CSV مخصص للاستبدال؟

1. قم بإنشاء ملف CSV جديد بعمودين
2. العمود الأول: جذور الكلمات الإسبرانتية
3. العمود الثاني: الترجمات العربية أو الأحرف الصينية المقابلة
4. احفظ الملف بتنسيق UTF-8
5. استخدم هذا الملف في صفحة إنشاء ملفات JSON

### ما هي وظيفة ملفات JSON لتجزئة الجذور؟

هذه الملفات تحدد كيفية تقسيم الكلمات الإسبرانتية إلى جذور وكيفية التعامل مع اللواحق والبادئات. على سبيل المثال:

```json
["am", "dflt", ["verbo_s1"]]
```

هذا يعني:
- "am" هو جذر الكلمة
- "dflt" تعني استخدام الأولوية الافتراضية
- "verbo_s1" تعني إضافة نهايات الفعل (is, as, os, ...)

## استكشاف الأخطاء وإصلاحها

### الرسالة: "تعذر تحميل ملف JSON الافتراضي"

**المشكلة**: قد لا يتمكن التطبيق من العثور على ملف JSON الافتراضي.

**الحل**:
1. تأكد من أن التطبيق لديه إذن الوصول إلى المجلد الذي يحتوي على الملفات
2. حاول تحميل ملف JSON مخصص بدلاً من استخدام الملف الافتراضي
3. إذا استمرت المشكلة، أعد تشغيل التطبيق

### لا يتم استبدال بعض الكلمات كما هو متوقع

**المشكلة**: قد لا يتم استبدال بعض الكلمات أو قد يتم استبدالها بشكل غير صحيح.

**الحل**:
1. تأكد من أن الكلمات موجودة في ملف CSV وملف JSON
2. تحقق من تنسيق الإدخال والإخراج المحدد
3. جرب إحاطة الكلمات المشكلة بعلامة @ للاستبدال الموضعي
4. تأكد من أن الكلمات ليست محاطة بعلامة % التي تمنع الاستبدال

### المعالجة بطيئة جدًا للنصوص الكبيرة

**المشكلة**: قد تستغرق معالجة النصوص الكبيرة وقتًا طويلاً.

**الحل**:
1. فعّل المعالجة المتوازية من قسم الإعدادات المتقدمة
2. زد عدد العمليات المتزامنة (حتى 4 أو أكثر إذا كان جهازك يدعم ذلك)
3. قسّم النص الكبير إلى أجزاء أصغر وعالج كل جزء على حدة
4. استخدم ملف JSON أصغر يحتوي فقط على الجذور الضرورية

### تنسيق HTML لا يظهر بشكل صحيح

**المشكلة**: قد لا تظهر تعليقات Ruby أو التنسيق HTML بشكل صحيح.

**الحل**:
1. تأكد من استخدام متصفح حديث يدعم تعليقات Ruby HTML
2. تحقق من تنسيق الإخراج المحدد
3. جرب خيارات التنسيق الأخرى مثل "تنسيق باستخدام الأقواس"
4. استخدم زر "تنزيل النتيجة" وافتح الملف في محرر HTML للتحقق من الكود
