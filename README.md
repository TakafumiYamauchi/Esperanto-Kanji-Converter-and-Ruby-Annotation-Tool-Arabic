# دليل استخدام "أداة استبدال نصوص الإسبرانتو بالأحرف الصينية (كانجي)"

## مقدمة

هذا التطبيق هو أداة متخصصة لمتعلمي لغة الإسبرانتو، تمكنك من استبدال كلمات الإسبرانتو بالأحرف الصينية (كانجي) أو بالترجمات العربية، مع إضافة تعليقات توضيحية بتنسيق HTML. يساعد هذا المستخدمين العرب على فهم وتذكر جذور كلمات الإسبرانتو من خلال ربطها بكلمات أو أحرف مألوفة لديهم.

يتكون التطبيق من صفحتين رئيسيتين:
1. **الصفحة الرئيسية (main.py)**: حيث يمكنك إدخال نص بالإسبرانتو وتحويله مباشرة.
2. **صفحة إنشاء ملف JSON**: لإنشاء قواعد استبدال مخصصة يمكن استخدامها في الصفحة الرئيسية.

## ميزات التطبيق

* استبدال نصوص الإسبرانتو بالأحرف الصينية (كانجي) أو بترجمات عربية
* عرض النتائج بتنسيقات مختلفة (HTML مع تعليقات Ruby، أو بالأقواس، أو باستبدال بسيط)
* إمكانية استثناء أجزاء من النص من عملية الاستبدال
* إمكانية تطبيق استبدالات موضعية ضمن أجزاء محددة من النص
* دعم المعالجة المتوازية لتسريع معالجة النصوص الكبيرة
* إمكانية تخصيص قائمة الاستبدالات عبر رفع ملفات CSV أو JSON خاصة بك

## استخدام الصفحة الرئيسية (أداة الاستبدال)

### الخطوة 1: تحميل قواعد الاستبدال (ملف JSON)

يمكنك اختيار أحد الخيارين:
* **استخدام ملف JSON الافتراضي**: يحتوي على مجموعة كبيرة من قواعد الاستبدال المعدة مسبقًا.
* **تحميل ملف خاص**: إذا كنت قد أنشأت ملف JSON مخصص، يمكنك تحميله هنا.

تحت هذا القسم يوجد خيار لتنزيل ملف JSON تجريبي يمكنك استخدامه كمرجع.

### الخطوة 2: اختيار تنسيق الإخراج

اختر نوع التنسيق المناسب من القائمة المنسدلة:

* **تنسيق HTML مع تعليقات Ruby وضبط الحجم**: يعرض النص الأصلي مع تعليقات توضيحية فوقه بحجم يتناسب مع طول النص.
* **تنسيق HTML مع تعليقات Ruby وضبط الحجم واستبدال الأحرف (كانجي)**: يستبدل النص بالكانجي مع عرض النص الأصلي كتعليق توضيحي.
* **تنسيق HTML**: تنسيق HTML قياسي دون ضبط الحجم.
* **تنسيق HTML مع استبدال الأحرف (كانجي)**: استبدال النص بالكانجي مع تنسيق HTML عادي.
* **تنسيق باستخدام الأقواس**: يعرض النص الأصلي مع الترجمة بين قوسين.
* **تنسيق باستخدام الأقواس واستبدال الأحرف (كانجي)**: يعرض الكانجي مع النص الأصلي بين قوسين.
* **الاحتفاظ فقط بالنص المُستبدل (استبدال بسيط)**: يعرض فقط نتيجة الاستبدال دون النص الأصلي.

### الخطوة 3: إدخال النص

يمكنك اختيار إحدى الطريقتين:
* **إدخال يدوي**: كتابة النص مباشرة في مربع النص.
* **تحميل ملف**: تحميل ملف نصي بترميز UTF-8 يحتوي على النص المراد معالجته.

### الخطوة 4: إعدادات عرض الأحرف الخاصة

اختر كيفية عرض الأحرف الخاصة بلغة الإسبرانتو:
* **إضافة علامة تمييز فوق الحرف (ĉ → c + ˆ)**: استخدام الأحرف مع علامات التمييز فوقها.
* **صيغة x (ĉ → cx)**: استخدام حرف x للتعبير عن الأحرف الخاصة.
* **صيغة ^ (ĉ → c^)**: استخدام رمز ^ للتعبير عن الأحرف الخاصة.

### الخطوة 5: المعالجة المتوازية (إعدادات متقدمة)

يمكنك تفعيل "المعالجة المتوازية" لتسريع معالجة النصوص الكبيرة، مع تحديد عدد العمليات المتزامنة المناسب لجهازك.

### الخطوة 6: بدء المعالجة

انقر على زر "إرسال" لبدء عملية الاستبدال. بعد الانتهاء، سترى النتائج في الأسفل مع إمكانية:
* معاينة النتيجة بتنسيق HTML
* عرض كود HTML الناتج
* تنزيل الملف الناتج

## نصائح لاستخدام الأداة بفعالية

### استخدام رموز خاصة في النص

* **إحاطة جزء من النص بعلامة %**: مثال: `%هذا النص لن يتم استبداله%`
  يتم تجاهل النص المحاط بعلامة % أثناء عملية الاستبدال ويبقى كما هو في النتيجة النهائية.

* **إحاطة جزء من النص بعلامة @**: مثال: `@هذا نص سيتم استبداله محلياً@`
  يتم استبدال النص المحاط بعلامة @ بشكل موضعي ضمن هذا الجزء المحدد فقط.

### التعامل مع النصوص الكبيرة

* للنصوص الكبيرة جدًا، من الأفضل تفعيل "المعالجة المتوازية" مع ضبط عدد العمليات المتزامنة على 3 أو 4.
* عند معالجة ملفات كبيرة، سيتم عرض معاينة محدودة فقط (الـ 247 سطرًا الأولى و3 أسطر الأخيرة).

## إنشاء ملف JSON للاستبدال (الصفحة الثانية)

إذا كنت ترغب في إنشاء قواعد استبدال مخصصة، يمكنك الانتقال إلى الصفحة الثانية من التطبيق.

### الخطوة 1: تجهيز ملف CSV

يمكنك اختيار:
* **رفع ملف CSV**: يحتوي على الجذور الإسبرانتية والمعلومات الترجمية (الأحرف الصينية أو الترجمات العربية).
* **استخدام الملف الافتراضي**: ملف CSV متاح مسبقًا في التطبيق.

تنسيق ملف CSV المطلوب:
- العمود الأول: جذر الكلمة بالإسبرانتو
- العمود الثاني: الترجمة أو الحرف الصيني المقابل

### الخطوة 2: تحضير ملفات JSON (لتجزئة الجذور)

يمكنك اختيار:
* **رفع ملف JSON**: ملف يحتوي على قواعد تجزئة الجذور الإسبرانتية.
* **استخدام الملف الافتراضي**: استخدام إعدادات التجزئة الافتراضية.

بالإضافة إلى تحضير ملف JSON آخر لإعدادات النص المستبدل.

### الخطوة 3: إعدادات المعالجة المتوازية

يمكنك تفعيل "المعالجة المتوازية" مع تحديد عدد العمليات المتزامنة لتسريع إنشاء ملف JSON.

### الخطوة 4: إنشاء ملف JSON

انقر على زر "إنشاء ملف JSON للاستبدال" لإنشاء ملف JSON الذي يمكن تنزيله واستخدامه في الصفحة الرئيسية.

## الملفات النموذجية المتاحة للتنزيل

التطبيق يقدم عدة ملفات نموذجية للتنزيل:

1. **ملف CSV نموذجي (جذور إسبرانتو – ترجمة عربية + روبي)**: يربط بين جذور الإسبرانتو والترجمات العربية مع تعليقات توضيحية.

2. **ملفات CSV للجذور الإسبرانتية والأحرف الصينية**: تربط بين جذور الإسبرانتو والأحرف الصينية.

3. **ملف JSON لإعدادات تجزئة الجذور الإسبرانتية**: يستخدم لتحديد كيفية تجزئة الكلمات إلى جذور، وترتيب استبدالها.

4. **ملف JSON لإعدادات النص المستبدل**: لتعيين أحرف صينية أو تنسيق مخصص لبعض الكلمات.

5. **ملف Excel يحتوي على 4736 جذر إسبرانتو مع ترجمات بـ 14 لغة**: مرجع شامل للجذور الإسبرانتية مع ترجمات متعددة اللغات.

## المفاهيم الأساسية المستخدمة في التطبيق

### جذور اللغة الإسبرانتية

الإسبرانتو لغة تعتمد بشكل كبير على نظام الجذور واللواحق. على سبيل المثال:
- الكلمة "lerni" (بمعنى "يتعلم") تتكون من الجذر "lern" واللاحقة "i" للدلالة على المصدر.
- يمكن اشتقاق كلمات أخرى مثل "lernejo" (مدرسة) من نفس الجذر مع لاحقة "ejo" (مكان).

### تنسيقات العرض

#### تنسيق Ruby HTML
تنسيق HTML الذي يسمح بعرض تعليقات توضيحية فوق النص الأصلي:
```html
<ruby>lerni<rt>يتعلم</rt></ruby>
```

يظهر هذا على الشكل:
<ruby>lerni<rt>يتعلم</rt></ruby>

#### تنسيق الأقواس
يعرض النص الأصلي مع الترجمة بين قوسين:
```
lerni(يتعلم)
```

## أمثلة للاستخدام

### مثال 1: استبدال نص بسيط
1. اختر "استخدام ملف JSON الافتراضي"
2. اختر "تنسيق HTML مع تعليقات Ruby وضبط الحجم"
3. أدخل نصًا بالإسبرانتو، مثل: `Mi lernas Esperanton.`
4. انقر على "إرسال"

النتيجة ستظهر الجملة مع تعليقات توضيحية فوق كل كلمة.

### مثال 2: استخدام علامات % و @
1. أدخل: `Mi %ne% volas @lerni@ Esperanton.`
2. انقر على "إرسال"

النتيجة:
- كلمة "ne" لن يتم استبدالها
- كلمة "lerni" سيتم استبدالها بشكل موضعي
- باقي النص سيتم استبداله وفقًا لإعدادات الملف

## استكشاف الأخطاء وإصلاحها

### مشكلة: لا يتم استبدال بعض الكلمات
- **الحل**: تأكد من أن جذور هذه الكلمات موجودة في ملف JSON المستخدم. يمكنك استخدام صفحة إنشاء ملف JSON لإضافة جذور جديدة.

### مشكلة: النص الناتج كبير جدًا
- **الحل**: سيتم عرض معاينة محدودة فقط. استخدم زر "تنزيل النتيجة" للحصول على الملف الكامل.

### مشكلة: بطء في المعالجة
- **الحل**: فعّل "المعالجة المتوازية" وزد عدد العمليات المتزامنة (ضمن حدود قدرة جهازك).
