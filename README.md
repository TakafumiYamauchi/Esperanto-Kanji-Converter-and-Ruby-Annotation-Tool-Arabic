سأقوم بإعداد دليل استخدام مفصل باللغة العربية لتطبيق استبدال النصوص الإسبرانتية بالأحرف الصينية (كانجي) أو إضافة تعليقات توضيحية. بعد دراسة الكود بعناية، إليك دليل الاستخدام:

# دليل استخدام أداة استبدال نصوص إسبرانتو بالأحرف الصينية (كانجي) وإضافة تعليقات توضيحية

## مقدمة

هذا التطبيق هو أداة مبتكرة تتيح لك استبدال كلمات وجذور لغة الإسبرانتو بالأحرف الصينية (كانجي) أو إضافة تعليقات توضيحية بتنسيق HTML لتسهيل تعلم وفهم اللغة. يعمل التطبيق على تحليل النص الإسبرانتو وتطبيق مجموعة من قواعد الاستبدال المخزنة في ملفات JSON، مما يتيح لك تحويل النصوص الإسبرانتية إلى عدة أشكال مختلفة، مثل نصوص مع تعليقات روبي (Ruby) أو استبدال الكلمات بأحرف صينية مع الحفاظ على المعنى.

## الميزات الرئيسية

- استبدال نصوص إسبرانتو بالأحرف الصينية (كانجي)
- إضافة تعليقات توضيحية (روبي) بتنسيق HTML
- دعم أنماط مختلفة للإخراج (HTML، تنسيق الأقواس، استبدال بسيط)
- خيارات متعددة لعرض الأحرف الخاصة بلغة الإسبرانتو
- قابلية تخصيص عملية الاستبدال باستخدام ملفات JSON
- إمكانية استثناء أجزاء معينة من النص من عملية الاستبدال
- دعم المعالجة المتوازية لتحسين الأداء مع النصوص الكبيرة

## تنظيم التطبيق

يتكون التطبيق من جزأين رئيسيين:

1. **الصفحة الرئيسية (main.py)**: تستخدم لاستبدال النصوص الإسبرانتية بالأحرف الصينية أو إضافة تعليقات توضيحية.
2. **صفحة إنشاء ملفات JSON (صفحة لإنشاء ملف JSON لاستبدال النصوص بالإسبرانتو بسلاسل نصية (كانجي).py)**: تستخدم لإنشاء ملفات JSON المخصصة التي تحتوي على قواعد الاستبدال.

## الصفحة الرئيسية - استبدال النصوص

### الخطوة 1: تحديد ملف JSON (قواعد الاستبدال)

أول خطوة هي تحديد ملف JSON الذي يحتوي على قواعد الاستبدال. يمكنك:

- **استخدام ملف JSON الافتراضي**: هذا هو الخيار الأبسط إذا كنت تستخدم التطبيق لأول مرة.
- **تحميل ملف JSON مخصص**: إذا كنت قد أنشأت ملف JSON خاص بك باستخدام الصفحة الثانية، يمكنك تحميله هنا.

لتنزيل ملف JSON تجريبي، انقر على "تنزيل ملف JSON تجريبي" ضمن قسم "تنزيل ملف JSON تجريبي (للاستبدال)".

### الخطوة 2: إعدادات متقدمة (اختيارية)

في قسم "إعدادات متقدمة (المعالجة المتوازية)"، يمكنك:

- تفعيل المعالجة المتوازية: تحسن الأداء عند العمل على نصوص كبيرة.
- تحديد عدد العمليات المتزامنة: بشكل افتراضي، سيتم استخدام 4 عمليات.

### الخطوة 3: اختيار تنسيق الإخراج

اختر التنسيق الذي تريد الحصول عليه بعد الاستبدال:

- **تنسيق HTML مع تعليقات Ruby وضبط الحجم**: يعرض النص الإسبرانتو مع تعليقات توضيحية فوقه بحجم مناسب.
- **تنسيق HTML مع تعليقات Ruby وضبط الحجم واستبدال الأحرف (كانجي)**: يستبدل النص بالأحرف الصينية مع إضافة التعليقات.
- **تنسيق HTML**: إضافة تعليقات توضيحية بتنسيق HTML بدون ضبط الحجم.
- **تنسيق HTML مع استبدال الأحرف (كانجي)**: استبدال النص بالأحرف الصينية مع تعليقات توضيحية.
- **تنسيق باستخدام الأقواس**: يضع التعليقات بين قوسين بعد كل كلمة إسبرانتو.
- **تنسيق باستخدام الأقواس واستبدال الأحرف (كانجي)**: يستبدل النص بالأحرف الصينية مع وضع النص الإسبرانتو بين قوسين.
- **الاحتفاظ فقط بالنص المُستبدل (استبدال بسيط)**: يستبدل النص الإسبرانتو بأحرف صينية فقط.

### الخطوة 4: تحديد مصدر النص الإدخالي

اختر طريقة إدخال النص الإسبرانتو:

- **إدخال يدوي**: كتابة النص مباشرة في مربع النص.
- **تحميل ملف**: تحميل ملف نصي بترميز UTF-8.

### الخطوة 5: إعدادات إضافية

- **اختيار شكل عرض الأحرف الخاصة بلغة الإسبرانتو في النتيجة**:
  - **إضافة علامة تمييز فوق الحرف**: يحول الأحرف المميزة مثل cx إلى ĉ.
  - **صيغة x**: يحول الأحرف المميزة إلى صيغة x (مثل ĉ → cx).
  - **صيغة ^**: يحول الأحرف المميزة إلى صيغة ^ (مثل ĉ → c^).

### الخطوة 6: إرسال النص للمعالجة

بعد إدخال النص، انقر على زر "إرسال" لبدء عملية الاستبدال. يمكنك النقر على "إلغاء" إذا كنت ترغب في إلغاء العملية.

### الخطوة 7: استعراض وتنزيل النتيجة

بعد المعالجة، ستظهر النتيجة في نافذة المعاينة. يمكنك:

- معاينة النتيجة في تبويب "معاينة HTML" إذا كان التنسيق المختار HTML.
- استعراض كود HTML في تبويب "النتيجة (كود HTML)".
- تنزيل النتيجة كملف HTML بالنقر على زر "تنزيل النتيجة".

## نصائح مهمة لاستخدام تقنيات خاصة في الصفحة الرئيسية

### استخدام علامات التجاهل (%)

يمكنك وضع أي جزء من النص بين علامتي % لتجاهله أثناء عملية الاستبدال. مثال:

```
Mi %ne volas% lerni Esperanton.
```

في هذا المثال، لن يتم استبدال كلمة "ne volas"، بينما سيتم استبدال باقي النص.

### استخدام علامات الاستبدال الموضعي (@)

يمكنك وضع جزء من النص بين علامتي @ لتطبيق استبدال موضعي فقط لذلك الجزء. هذا مفيد عندما تريد استبدال كلمة معينة بشكل مختلف عن باقي النص. مثال:

```
Mi volas @lerni@ Esperanton.
```

في هذا المثال، سيتم تطبيق استبدال خاص على كلمة "lerni" فقط.

## صفحة إنشاء ملفات JSON

إذا كنت تريد إنشاء ملف JSON مخصص لاستخدامه في عملية الاستبدال، انتقل إلى الصفحة الثانية من التطبيق "إنشاء ملف JSON لاستخدامه في استبدال النص (الأحرف الصينية) في نصوص إسبرانتو".

### الخطوة 1: تجهيز ملف CSV

في هذه الخطوة، تحتاج إلى ملف CSV يحتوي على الجذور الإسبرانتية والترجمات أو الأحرف الصينية المقابلة. يمكنك:

- **رفع ملف CSV مخصص**: تحميل ملف CSV أعددته بنفسك.
- **استخدام الملف الافتراضي**: استخدام ملف CSV مضمّن في التطبيق.

### الخطوة 2: تحضير ملفات JSON

تحتاج إلى ملفات JSON تحتوي على قواعد تجزئة الجذور الإسبرانتية و/أو النص المستبدل المخصص:

1. **ملف JSON لتجزئة الجذور الإسبرانتية**: يحدد كيفية تقسيم الكلمات الإسبرانتية إلى جذور.
2. **ملف JSON للنص المستبدل**: يحدد التنسيق المخصص لبعض الكلمات (اختياري).

لكل منهما، يمكنك رفع ملف مخصص أو استخدام الملف الافتراضي.

### الخطوة 3: إعدادات متقدمة (المعالجة المتوازية)

كما في الصفحة الرئيسية، يمكنك تفعيل المعالجة المتوازية وتحديد عدد العمليات المتزامنة.

### الخطوة 4: إنشاء ملف JSON النهائي

انقر على زر "إنشاء ملف JSON للاستبدال" للبدء في إنشاء ملف JSON المخصص. بعد الانتهاء، ستتمكن من تنزيل ملف JSON الناتج واستخدامه في الصفحة الرئيسية.

## تنسيقات ملفات CSV وJSON المستخدمة

### تنسيق ملف CSV للجذور والترجمات

يجب أن يحتوي ملف CSV على الأعمدة التالية:

- **العمود الأول**: جذر الكلمة الإسبرانتية
- **العمود الثاني**: الترجمة أو الأحرف الصينية المقابلة

مثال:
```
ami,حب
bird,طائر
lang,لغة
```

### تنسيق ملف JSON لتجزئة الجذور

يحدد هذا الملف كيفية تجزئة الكلمات الإسبرانتية وترتيب استبدالها. على سبيل المثال:

```json
[
  ["am", "dflt", ["verbo_s1"]],
  ["lingv", "dflt", ["o", "a", "e"]]
]
```

هذا يعني:
- استبدال جذر "am" مع إضافة لواحق الفعل ("verbo_s1" تشير إلى اللواحق مثل as, is, os الخ).
- استبدال جذر "lingv" مع إضافة لواحق الاسم "o"، الصفة "a"، والظرف "e".

### تنسيق ملف JSON للنص المستبدل

يسمح هذا الملف بتعيين تنسيق مخصص لكلمات معينة. مثال:

```json
[
  ["am/ik", "dflt", ["o", "a"], "حب/صداقة"]
]
```

هذا يعني استبدال جذر "amik" (مقسم إلى "am/ik") بالنص "حب/صداقة" مع إضافة لواحق "o" و "a".

## أمثلة عملية

### مثال 1: استبدال بسيط

النص الإدخالي:
```
Mi amas vin.
```

النتيجة (باستخدام تنسيق HTML مع تعليقات Ruby):
```html
<ruby>Mi<rt>أنا</rt></ruby> <ruby>am<rt>حب</rt></ruby><ruby>as<rt>زمن الحاضر</rt></ruby> <ruby>vin<rt>أنت (مفعول به)</rt></ruby>.
```

### مثال 2: استخدام علامات التجاهل

النص الإدخالي:
```
Mi %amas% vin.
```

النتيجة:
```html
<ruby>Mi<rt>أنا</rt></ruby> amas <ruby>vin<rt>أنت (مفعول به)</rt></ruby>.
```

### مثال 3: استخدام علامات الاستبدال الموضعي

النص الإدخالي:
```
Mi @amas@ vin.
```

النتيجة:
```html
<ruby>Mi<rt>أنا</rt></ruby> <ruby>amas<rt>يحب</rt></ruby> <ruby>vin<rt>أنت (مفعول به)</rt></ruby>.
```

## نصائح للاستخدام الأمثل

1. **ابدأ بالملفات الافتراضية**: استخدم الملفات الافتراضية للتعرف على كيفية عمل التطبيق.

2. **تجربة التنسيقات المختلفة**: جرّب تنسيقات الإخراج المختلفة لتحديد الأنسب لاحتياجاتك.

3. **استخدام علامات % و @**: استفد من هاتين العلامتين للتحكم في كيفية استبدال أجزاء معينة من النص.

4. **المعالجة المتوازية للنصوص الكبيرة**: فعّل المعالجة المتوازية عند العمل على نصوص كبيرة لتحسين الأداء.

5. **تخصيص ملفات JSON**: إذا كنت بحاجة إلى قواعد استبدال مخصصة، استخدم الصفحة الثانية لإنشاء ملف JSON مخصص.

6. **استخدام تنسيق الأقواس للنصوص البسيطة**: إذا كنت لا تحتاج إلى عرض التعليقات بتنسيق HTML، استخدم تنسيق الأقواس للحصول على نتائج أبسط.

## الدعم واستكشاف الأخطاء وإصلاحها

### مشاكل شائعة وحلولها

1. **رسالة خطأ: "تعذر تحميل ملف JSON"**
   - تأكد من أن الملف بتنسيق JSON صحيح.
   - حاول استخدام الملف الافتراضي بدلاً من ملفك المخصص.

2. **عدم ظهور التعليقات التوضيحية**
   - تأكد من اختيار تنسيق إخراج يدعم التعليقات (مثل تنسيقات HTML).
   - تحقق من وجود الكلمات الإسبرانتية في ملف JSON المستخدم.

3. **استبدال غير صحيح للكلمات**
   - تأكد من عدم وجود أخطاء إملائية في النص الإسبرانتو.
   - قد تحتاج إلى تعديل ملف JSON للتعامل مع حالات خاصة.

4. **بطء في المعالجة**
   - فعّل المعالجة المتوازية وزيد عدد العمليات المتزامنة.
   - قسّم النصوص الكبيرة جداً إلى أجزاء أصغر.

## الخلاصة

هذا التطبيق هو أداة قوية لاستبدال نصوص إسبرانتو بالأحرف الصينية أو إضافة تعليقات توضيحية، مما يسهل على متعلمي اللغة فهم وتذكر المفردات والتراكيب الإسبرانتية. باستخدام الميزات المختلفة المتاحة، يمكنك تخصيص عملية الاستبدال لتلبية احتياجاتك الخاصة، سواء كنت تبحث عن تعليقات توضيحية بتنسيق HTML أو مجرد استبدال بسيط للنصوص.

من خلال فهم كيفية استخدام ملفات JSON والتحكم في عملية الاستبدال باستخدام علامات خاصة مثل % و @، يمكنك الوصول إلى أقصى استفادة من هذا التطبيق وتسريع عملية تعلم لغة الإسبرانتو.
